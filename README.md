# SnoopFi: Defeating CSI Obfuscation Mechanisms: A Study on Unauthorized Wi-Fi Sensing in Wireless Sensor Network
SnoopFi is an attack scheme that supports effective physical environment eavesdropping under the CSI obfuscation protection mechanism.
In this repository, we have released some of the unobfuscated, obfuscated, and SnoopFi deobfuscated CSI datasets we collected. In addition, we have also open-sourced the positioning model and obfuscation prediction algorithm.
